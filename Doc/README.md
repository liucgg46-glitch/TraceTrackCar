# TraceTrackCar 文档

本目录只保存当前 STM32F407ZG 工程的稳定说明。源码、配置头文件和公共接口是最终依据；文档不记录临时测试进度或当前正在注册的任务表。

## 文档索引

- [工程说明](工程说明.md)：分层、启动流程、目录和构建规则。
- [参数与引脚](参数与引脚.md)：主要配置入口、外设参数和接线。
- [测试任务](测试任务.md)：专项测试开关、任务组合和测试入口。
- [通信说明](通信说明.md)：调试串口、E220 和 K210。
- [上板与注意事项](上板与注意事项.md)：安全、联调顺序和常见问题。

## 维护规则

- 测试入口以 `Test/test.h` 为准。
- 正常运行指示使用 `AppDiagnostics_HeartbeatUpdate()`。
- `Test_GPIO_Toggle()`只是普通 GPIO 翻转测试，不作为运行指示灯任务。
- 详细调参值以源码头文件为准，避免文档和代码长期不一致。
