# STM32F407原工程通信说明

## 1. 端口分工

| 用途 | 硬件和引脚 |
| --- | --- |
| 调试日志 | USART1：PA9 TX、PA10 RX，115200 8N1 |
| K210 | USART2：PA2 TX、PA3 RX，115200 8N1 |
| E220 | USART1：PA9 TX、PA10 RX，PE6 AUX |

上层统一使用 `DEBUG_UART_PORT`、`UART_PORT_K210`和 `UART_PORT_E220`。

## 2. E220 双向测试完整任务表

```c
#define APP_SCHEDULER_TASK_LIST_DEFINE()                         \
Task_t task_list[] = {                                           \
    { AppDiagnostics_HeartbeatUpdate, 10U, 0U }, /* 运行心跳 */         \
    { AppTask_BSP_Background, 1U, 0U }, /* UART、总线和异步驱动后台 */        \
    { Test_E220_Link_Update, 10U, 0U }, /* E220 双向通信 */             \
};                                                               \
const uint8_t TASK_NUM =                                         \
    (uint8_t)(sizeof(task_list) / sizeof(task_list[0]))
```

`BSP/vehicle_config.h`选择 `VEHICLE_UART1_LINK_E220`，PA9/PA10 接 E220，PE6 接 AUX。两台设备发送 `E220,本机ID,递增数字\r\n`，屏幕显示 SELF、TX、PEER、RX、接收计数和链路状态。

调试串口与 E220 共用 USART1，E220 测试主要看 LCD/OLED，不混入普通日志。

## 4. UART 发送接口

- `BSP_UART_Write()`：日志流，可部分写入；
- `BSP_UART_WriteFrame()`：完整帧写入；
- `BSP_UART_WriteFrameNow()`：Driver 重试队列使用。
#K210 LAB 阈值现场调参通信协议

1. 功能说明

为了方便比赛现场根据实际光照条件快速调整视觉阈值，K210 道路视觉程序增加了 LAB 阈值在线调参功能。

调参过程中由 STM32 通过 USART2 向 K210 发送控制命令，K210 接收到命令后进入二值化预览界面，并实时修改当前 LAB 阈值。

该功能不需要重新连接 CanMV IDE，也不需要重新修改 SD 卡程序，即可完成运行过程中的临时阈值调整。

当前已经完成 STM32 与 K210 的串口通信、LAB 调参命令解析以及按键调参的实机验证。

4. LAB 调参命令

LAB 在线调参使用三个命令：

0x41  LAB_TUNE_MODE
0x42  LAB_TUNE_SELECT
0x43  LAB_TUNE_ADJUST

对应功能：

0x41：进入、切换或退出 LAB 调参模式
0x42：选择当前需要修改的 LAB 参数
0x43：增加或减小指定 LAB 参数

4.1 0x41：LAB 调参模式控制

命令字：

CMD = 0x41

数据定义：

D1

功能

0

退出 LAB 调参模式

1

RED 红色阈值调参

2

BLACK 黑色阈值调参

其中：

D2 = 0
D3 = 0

进入 RED 调参：

K210_Comm_SetLabTuneMode(K210_LAB_TUNE_RED);

进入 BLACK 调参：

K210_Comm_SetLabTuneMode(K210_LAB_TUNE_BLACK);

退出调参：

K210_Comm_SetLabTuneMode(K210_LAB_TUNE_OFF);

进入 RED 或 BLACK 调参模式后，K210 暂停正常道路识别显示，进入 LAB 二值化预览界面。

调参页面中：

白色区域 = 当前 LAB 阈值命中的像素
黑色区域 = 当前 LAB 阈值未命中的像素

退出 LAB 调参模式后恢复正常道路视觉识别。

5. LAB 参数范围

K210 对各通道参数进行范围限制：

L：0 ～ 100
A：-128 ～ 127
B：-128 ～ 127

当前程序只进行各 LAB 通道数值范围限制，不额外强制：

MIN <= MAX

比赛现场以 CanMV/K210 实际二值化识别效果为主要判断标准，不应在 STM32 通信层自行交换 MIN/MAX。

15. 比赛现场推荐调参流程

1. 固定车辆和目标位置
2. 进入 RED 或 BLACK LAB TUNE
3. 观察 WHITE=MATCH
4. NEXT 选择参数
5. 使用 +5 / -5 调节
6. 让目标区域尽量完整变白
7. 同时减少背景误匹配

9. 改变摄像头轻微倾角测试
10. 加入阴影测试
11. 确认稳定后退出 LAB TUNE
12. 恢复正常道路视觉
13. 最后进行实车闭环测试

+
轻微角度变化
+
现场光照变化
+
