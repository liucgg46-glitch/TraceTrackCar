# STM32F407 通信说明

## 1. 语义端口

```c
#define UART_PORT_DEBUG  UART_PORT1
#define UART_PORT_E220   UART_PORT1
#define UART_PORT_K210   UART_PORT2
#define DEBUG_UART_PORT  UART_PORT_DEBUG
```

| 用途 | 硬件 | 引脚 |
| --- | --- | --- |
| 调试 / E220 | USART1 | PA9 TX，PA10 RX |
| K210 | USART2 | PA2 TX，PA3 RX |

调试串口与 E220 共用 USART1。E220 模式下普通日志也会进入无线链路。

## 2. E220

配置位于 `BSP/vehicle_config.h`。

```text
PA9  / USART1_TX → E220 RXD
PA10 / USART1_RX ← E220 TXD
PE6              ← E220 AUX
GND              ↔ E220 GND
```

透明传输模式下 M0、M1 必须可靠拉低。两端模块的 UART 参数、信道、空中速率和地址配置必须能够互通。

双向测试帧：

```text
E220,SELF_ID,VALUE\r\n
```

测试任务保留 `AppTask_BSP_Background()` 和 `Test_E220_Link_Update()`。

## 3. K210

K210 使用 USART2、115200、8N1。协议层位于：

```text
APP/k210_comm.c
APP/k210_comm.h
```

支持单数字、多数字快照、道路状态、视觉快照和道路档位配置。接收解析任务：

```c
{ K210_Comm_Update, 5U, 0U },
```

上层只调用 `K210_Comm_*` 公共接口，不直接读取 USART2 原始字节。

## 4. 发送接口

- `BSP_UART_Write()`：日志流，可部分写入。
- `BSP_UART_WriteFrame()`：完整帧写入，空间不足返回忙。
- `BSP_UART_WriteFrameNow()`：Driver 重试队列内部使用。

协议数据使用完整帧接口。
