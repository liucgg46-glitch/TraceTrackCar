# STM32F407原工程通信说明

## 1. 端口分工

| 用途 | 硬件和引脚 |
| --- | --- |
| 调试日志 | USART1：PA9 TX、PA10 RX，115200 8N1 |
| K210 | USART2：PA2 TX、PA3 RX，115200 8N1 |
| E220 | USART1：PA9 TX、PA10 RX，PE6 AUX |

上层统一使用 `DEBUG_UART_PORT`、`UART_PORT_K210`和 `UART_PORT_E220`。

## 2. E220 双向测试完整任务表

```c
#define APP_SCHEDULER_TASK_LIST_DEFINE()                         \
Task_t task_list[] = {                                           \
    { AppDiagnostics_HeartbeatUpdate, 10U, 0U }, /* 运行心跳 */         \
    { AppTask_BSP_Background, 1U, 0U }, /* UART、总线和异步驱动后台 */        \
    { Test_E220_Link_Update, 10U, 0U }, /* E220 双向通信 */             \
};                                                               \
const uint8_t TASK_NUM =                                         \
    (uint8_t)(sizeof(task_list) / sizeof(task_list[0]))
```

`BSP/vehicle_config.h`选择 `VEHICLE_UART1_LINK_E220`，PA9/PA10 接 E220，PE6 接 AUX。两台设备发送 `E220,本机ID,递增数字\r\n`，屏幕显示 SELF、TX、PEER、RX、接收计数和链路状态。

调试串口与 E220 共用 USART1，E220 测试主要看 LCD/OLED，不混入普通日志。

## 3. K210 单数字测试完整任务表

```c
#define APP_SCHEDULER_TASK_LIST_DEFINE()                         \
Task_t task_list[] = {                                           \
    { AppDiagnostics_HeartbeatUpdate, 10U, 0U }, /* 运行心跳 */         \
    { AppTask_BSP_Background, 1U, 0U }, /* UART、总线和异步驱动后台 */        \
    { K210_Comm_Update, 5U, 0U }, /* K210 帧解析 */                    \
    { Test_K210_SingleDigitCommUpdate, 10U, 0U }, /* 单数字测试 */       \
};                                                               \
const uint8_t TASK_NUM =                                         \
    (uint8_t)(sizeof(task_list) / sizeof(task_list[0]))
```

K210 为 115200、8N1。多数字、道路状态和档位发送的完整任务表见《测试任务完整手册》。

## 4. UART 发送接口

- `BSP_UART_Write()`：日志流，可部分写入；
- `BSP_UART_WriteFrame()`：完整帧写入；
- `BSP_UART_WriteFrameNow()`：Driver 重试队列使用。
