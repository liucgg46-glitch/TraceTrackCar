# STM32F407原工程上板与注意事项

## 1. 首次上电

1. 断开电机功率，只给主控和低功耗模块供电。
2. 检查 3V3 与 GND 是否短路。
3. 主控、传感器、K210、E220 和电机驱动逻辑地共地。
4. 数字信号使用 3.3 V 逻辑。
5. 电机和舵机使用独立电源。

## 2. 推荐测试顺序

1. 下载和心跳；
2. GPIO、按键、灯、蜂鸣器；
3. 调试 UART；
4. I2C、SPI、LCD/OLED；
5. K210、E220；
6. 灰度、ToF、HX711、ICM20948；
7. 编码器；
8. 电机开环；
9. 底盘闭环；
10. 动作、循迹、路线和整车状态机。

## 3. 安全规则

- 电机、底盘和动作首次测试必须悬空车轮；
- 同时只允许一个任务控制电机；
- `AppTask_BSP_Background()`不能删除；
- E220 或显示专项测试时不要注册其他显示页面；
- 测试结束后恢复正式任务表和 `PROJECT_TEST_TASKS_ENABLE=0U`。

## 4. 2WD / 4WD

2WD 下 SPI1 可用于 LCD；4WD 下 PA6/PA7 被后轮编码器占用，LCD 改用 SPI2。4WD 时 LCD 与 ICM20948 共用 SPI2，必须使用独立 CS。
