# STM32F407原工程上板与注意事项

## 1. 首次上电

1. 断开电机功率，只给主控和低功耗模块供电。
2. 检查 3V3 与 GND 是否短路。
3. 主控、传感器、K210、E220 和电机驱动逻辑地共地。
4. 数字信号使用 3.3 V 逻辑。
5. 电机和舵机使用独立电源。
6. Yahboom 8路灰度模块接5V供电，串口`RX`接`PD8/USART3_TX`，串口`TX`接`PD9/USART3_RX`。

## 2. 推荐测试顺序

1. 下载和心跳；
2. GPIO、按键、灯、蜂鸣器；
3. 调试 UART；
4. I2C、SPI、LCD/OLED；
5. K210、E220；
6. 灰度、ToF、HX711、ICM20948；
7. 编码器；
8. 电机开环；
9. 底盘闭环；
10. 动作、循迹、路线和整车状态机。

钢球控制首次上板按以下顺序进行：

1. 使用`PROJECT_TEST_PROFILE_SERVO_CAL`确认机械安全范围和水平角；
2. 使用`PROJECT_TEST_PROFILE_K210_BALL_COMM`确认0x32坐标、状态和置信度；
3. 使用`PROJECT_TEST_PROFILE_BALL_MODEL_ID`固定输出±0.5°/±1.0°，确认方向并辨识B0；
4. 使用`PROJECT_TEST_PROFILE_BALL_STATE_CONTROL`分别验证O、+50 mm、-50 mm；
5. 三个目标稳定后恢复`PROJECT_TEST_TASKS_ENABLE=0U`，验证正式H3自动顺序。

## 3. 安全规则

- 电机、底盘和动作首次测试必须悬空车轮；
- 同时只允许一个任务控制电机；
- `AppTask_BSP_Background()`不能删除；
- E220 或显示专项测试时不要注册其他显示页面；
- Yahboom灰度模块使用串口数字量模式，默认连续收到有效帧且上电约3秒后允许在线；
- 白底应读取`raw=1/filt=4095`，黑线应读取`raw=0/filt=0`，不再进行模拟量阈值标定；
- 测试结束后恢复正式任务表和 `PROJECT_TEST_TASKS_ENABLE=0U`。
- 钢球闭环未连续获得3帧VALID时不会启动；HOLD和LOST不会作为新测量；
- 静止滚球测试保持底盘任务未注册，底盘IMU前馈默认关闭；
- 机械方向为舵机角小于局部平衡角时钢球向右、大于时钢球向左；
- B0和局部平衡角表完成实物辨识前保持±2.5°动态角限制。

## 4. 2WD / 4WD

2WD 下 SPI1 可用于 LCD；4WD 下 PA6/PA7 被后轮编码器占用，LCD 改用 SPI2。4WD 时 LCD 与 ICM20948 共用 SPI2，必须使用独立 CS。

当前Yahboom灰度串口占用`PD8/PD9`，与4WD右后轮方向脚冲突；启用该模块时使用2WD配置。
