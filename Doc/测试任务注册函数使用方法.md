# 测试任务注册函数使用方法

> 本文由同名 Word 文档迁移并按当前项目源码校正。Word 原文件保留；后续修改代码时应同步检查本文和 `说明文档.md`。

## 电机开环测试（默认 2WD 控制两个前电机；切换为 4WD 后控制四个电机）

```c
Task_t task_list[] = {
{ Test_GPIO_Toggle,        10U,  0U },  \
{ AppTask_BSP_Background,   1U,  0U },  \
{ Encoder_Update,          10U,  0U },  \
{ Test_MotorCmd_Update,    10U,  0U },  \
{ Test_MotorCmd_Log,      200U,  0U },  \
{ Test_DrvEncoder_Log,    200U,  0U },  \
};
```

w：左右电机均设为 +300‰，小车前进

s：左右电机均设为 -300‰，小车后退

a：左侧 -300‰、右侧 +300‰，原地左转

d：左侧 +300‰、右侧 -300‰，原地右转

0：立即停止

## 底盘速度闭环测试

```c
{ Test_GPIO_Toggle,        10U,  0U }, \
{ AppTask_BSP_Background,   1U,  0U },  \
{ Encoder_Update,          10U,  0U },  \
{ Chassis_Update,          10U,  0U },  \
{ Test_ChassisCmd_Update,  10U,  0U },  \
{ Test_ChassisCmd_Log,    200U,  0U },  \
```

g：线速度设为 +2000 cps，前进

b：线速度设为 -2000 cps，后退

l：转向速度设为 +1200 cps，原地左转

r：转向速度设为 -1200 cps，原地右转

x 或 0：停止

## 灰度传感器与循迹状态调试（此任务表未注册 Motion_Update 和 Chassis_Update，不会实际驱动电机）

```c
{ Test_GPIO_Toggle,      100U,  0U },  \
{ AppTask_BSP_Background,  1U,  0U }, \
{ Sensor_Update,           1U,   0U },   \
{ Encoder_Update,         10U,   0U },   \
{ LineTrack_Update,        10U, 0U },  \
{ Test_LineCmd_Update,     10U, 0U },  \
{ Test_LineCmd_Log,       200U, 0U },  \
```

·  w：将八路传感器全部放在白色区域，采集白色值。

·  b：将八路传感器全部放在黑色区域，采集黑色值。

·  t：根据白色和黑色值生成八路阈值。

·  d：将 8 路阈值统一设为 LINE_DETECT_DEFAULT_THRESHOLD（当前为 2000U）。

·  p：立即打印一次完整数据。

·  k：扫描 I2C1 设备。

·  1 / l / L：请求进入循迹状态（IMU 未就绪时可能被拒绝）。

·  0 或 x：停止循迹状态。

## LCD 测试

### 普通测试注册任务

```c
Task_t task_list[] = {
{ Test_GPIO_Toggle,        100U, 0U },   \
{ AppTask_BSP_Background,    1U, 0U },  \
{ Test_LCD_Ascii_Update,     50U, 0U },  \
};
```

注意：Test_LCD_Ascii_Update 是独占屏幕的 ASCII 测试任务，不要与周期性界面任务 LCD_Update 同时注册。

### 周期性调用lcd注册函数

```c
{ Test_GPIO_Toggle,        100U, 0U },   \
{ AppTask_BSP_Background,    1U, 0U },  \
{ Sensor_Update,             1U,   0U },  \
{ Encoder_Update,           10U,   0U },  \
{ LineTrack_Update,         10U,   0U },  \
{ Chassis_Update,           10U,   0U },  \
{ LCD_Update,             20U,   0U },   \
```

注意：运行时周期性刷新 LCD 时注册 LCD_Update（位置：APP/app_task_config.h）

修改 LCD 仪表盘内容：编辑 APP/lcd_ui.c 中的 LcdUi_ShowDashboard()；更新间隔在 APP/lcd_ui.h 的 LCD_UI_UPDATE_INTERVAL_MS 中修改。

Lcd显示内容和含义

TRACETRACK DASHBOARD

IMU:OK MAG:HU

R:+1.2 P:-0.5

YAW:+90.3 DEG

LINE:RUN SINGLE

MASK:18 ERR:-250

TGT L:600 R:600

FB L:590 R:610

PWM L:80 R:72

TOF:350 MM

### 含义

H：磁力计健康

U：当前正在使用磁力计修正

MASK：8路灰度黑线掩码

ERR：循迹位置误差

TGT：目标编码器速度

FB：编码器实际反馈速度

## OLED 测试

### 普通测试注册任务

```c
{ Test_GPIO_Toggle,        100U, 0U },   \
{ AppTask_BSP_Background,    1U, 0U },  \
{ Test_OLED_Ascii_Update,     20U, 0U }, \
```

注意：OLED_Update是周期性更新oled，不能和Test_OLED_Ascii_Update同时使用，Test_OLED_Ascii_Update只是测试oled功能

### 周期性调用oled注册函数

```c
{ Test_GPIO_Toggle,        100U, 0U },   \
{ AppTask_BSP_Background,    1U, 0U },  \
{ Sensor_Update,             1U,   0U },  \
{ Encoder_Update,           10U,   0U },  \
{ LineTrack_Update,         10U,   0U },  \
{ Chassis_Update,           10U,   0U },  \
{ OLED_Update,             20U,   0U },   \
```

注意：运行时周期性刷新 OLED 时注册 OLED_Update（位置：APP/app_task_config.h）

修改 OLED 仪表盘内容：编辑 APP/oled_ui.c 中的 OledUi_ShowDashboard()；更新间隔在 APP/oled_ui.h 的 OLED_UI_UPDATE_INTERVAL_MS 中修改。

Oled显示内容和含义

R:+1.2 P:-0.5

Y:+90.3 M:HU

LINE:RUN SINGLE

M:18 E:-250

T:600/600 F:590/610

P:80/72 D:350

### 含义

R/P/Y：Roll、Pitch、Yaw

M:HU：磁力计健康且正在参与修正

LINE：循迹状态和线路类型

M：灰度黑线掩码

E：循迹误差

T：左右目标速度

F：左右反馈速度

P：左右PWM

D：前方测距，单位mm

## 测试定距前进、后退及定角转弯

```c
{ Test_GPIO_Toggle,        100U, 0U },   \
{ AppTask_BSP_Background,    1U,   0U },  \
{ Sensor_Update,             1U,   0U },  \
{ Encoder_Update,           10U,   0U },  \
{ Test_MotionCmd_Update,    10U,   0U },  \
{ Motion_Update,            10U,   0U },  \
{ Chassis_Update,           10U,   0U },  \
{ Test_MotionCmd_Log,      200U,   0U },  \
```

L    左转 90°，最大转向速度 1600 cps

R    右转 90°，最大转向速度 1600 cps

x    立即停止

0    立即停止

f    前进 500 mm，速度 800 cps

v    后退 500 mm，速度 800 cps

## 测试循迹

```c
{ Test_GPIO_Toggle,       100U, 0U }, /* 运行指示灯 */   \
{ AppTask_BSP_Background,   1U, 0U },                   \
{ Sensor_Update,            1U, 0U },                   \
{ Encoder_Update,          10U, 0U },                   \
{ Test_RouteCmd_Update,    10U, 0U },                   \
{ LineTrack_Update,        10U, 0U },                   \
{ Motion_Update,           10U, 0U },                   \
{ Chassis_Update,          10U, 0U },                   \
{ Test_RouteLog,          200U, 0U },                   \
```

### 串口命令

l或1：开始循迹

x或0：停止

r：复位路线状态

p：立即打印Route状态
