# 测试任务注册函数使用方法

`Test/test.h`是专项测试公共入口的唯一依据。测试代码只在
`PROJECT_TEST_TASKS_ENABLE == 1U`时参与编译；完成专项测试后应将该宏恢复为
`0U`，由`APP/app_task_config.h`自动恢复正式任务表。

## PF8摆杆舵机安全标定

本测试只连接PF8的`TIM13_CH1`水平舵机。上电输出1500us并保持锁定，不自动
扫描；KEY1回中并解锁，KEY2增加5us，KEY3减少5us，KEY4立即回中并锁定，
KEY5打印状态。Driver将输出硬限制在1450～1550us。

当前`APP/app_task_config.h`已通过条件编译提供以下测试任务表：

```c
#define APP_SCHEDULER_TASK_LIST_DEFINE()                                            \
Task_t task_list[] = {                                                              \
    { AppDiagnostics_HeartbeatUpdate, 10U, 0U }, /* 运行心跳 */                    \
    { AppTask_BSP_Background, 1U, 0U }, /* UART和舵机Driver后台 */                 \
    { Key_Update, 10U, 0U }, /* 按键扫描和消抖 */                                  \
    { Test_ServoBeamCalibration_Update, 10U, 0U }, /* PF8舵机安全标定 */          \
};                                                                                  \
const uint8_t TASK_NUM =                                                             \
    (uint8_t)(sizeof(task_list) / sizeof(task_list[0]))
```

标定完成后，只需将`Test/test_config.h`中的
`PROJECT_TEST_TASKS_ENABLE`恢复为`0U`，无需手工改写正式H2任务表。

## 数字量基础循迹与整车状态机注册

`PROJECT_TEST_TASKS_ENABLE == 0U`时，正式基础循迹使用以下入口和顺序：

```c
#define APP_SCHEDULER_TASK_LIST_DEFINE()                                            \
Task_t task_list[] = {                                                              \
    { AppDiagnostics_HeartbeatUpdate, 10U, 0U }, /* 运行心跳 */                    \
    { AppTask_BSP_Background, 1U, 0U }, /* UART、总线和异步Driver后台 */          \
    { Key_Update, 10U, 0U }, /* 按键扫描 */                                        \
    { Sensor_Update, 1U, 0U }, /* 灰度、IMU和测距 */                               \
    { Encoder_Update, 10U, 0U }, /* 速度反馈 */                                    \
    { TaskProfile_Update, 10U, 0U }, /* 当前整车任务状态机 */                     \
    { LineTrack_Update, 10U, 0U }, /* 灰度、Route和基础循迹 */                    \
    { Motion_Update, 10U, 0U }, /* Route非阻塞动作 */                              \
    { Chassis_Update, 10U, 0U }, /* 底盘速度闭环 */                                \
    { LCD_Update, 20U, 0U }, /* 异步状态页面 */                                    \
};                                                                                  \
const uint8_t TASK_NUM =                                                             \
    (uint8_t)(sizeof(task_list) / sizeof(task_list[0]))
```

- `TaskProfile_Update()`只推进`APP/task_profile_config.h`选择的整车状态机；
- `LineTrack_Update()`内部完成灰度读取、LineDetect、RouteManager和LineTrack；
- `Motion_Update()`只推进Route申请的非阻塞动作；
- `Chassis_Update()`必须排在循迹和动作计算之后；
- 当前H题总状态机后续可以修改，但这些注册入口、周期和分层关系保持不变。
