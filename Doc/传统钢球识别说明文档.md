# 3. 钢球检测输出说明


示例：

```
BALL position=+0.51cm

state=VALID

confidence=100
```


---

## 3.1 position


定义：

```
左侧                     右侧

-12cm ---- 0cm ---- +12cm
```


例如：

```
+0.51cm
```

表示：

钢球位于中心右侧约：

```
0.51cm
```


正负：

|输出|含义|
|-|-|
|负数|钢球在左侧|
|0|中心|
|正数|钢球在右侧|


---

## 3.2 state


```
state=VALID
```


表示：

当前帧检测到有效钢球。


如果：

```
state=LOST
```

表示：

当前没有找到钢球。


---

## 3.3 confidence


注意：

这里不是YOLO置信度。


它表示：

```
规则算法检测质量
```


计算依据：

- 高亮像素数量
- 区域面积
- 宽高比例
- 连续性


例如：

```
confidence=100
```

表示：

当前钢球高亮区域质量最好。

# 5. 当前识别原理


## 5.1 钢球特点


钢球表面：

```
金属反光
```

导致：

```
钢球 = 局部高亮白点
```


因此：

利用灰度检测即可。


---

## 5.2 不再使用YOLO


YOLO方案：

缺点：

- 模型占用资源
- 推理速度慢
- 运动目标容易丢失


当前方案：

优点：

- 速度快
- 延迟低
- 参数容易现场调整
- 适合控制闭环

# 6. K210阈值参数


## 6.1 钢球参数


当前：

```python
BALL_MIN = 125
BALL_MAX = 255
```


含义：

```
0 ----------------255

黑色          白色
```


检测：

```
125~255
```

范围内的高亮区域。


---

## 6.2 钢球调整方法


### 钢球检测不到


降低：

```python
BALL_MIN
```


例如：

```
125 → 115
```


效果：

增加检测范围。


---

### 背景出现白点


提高：

```python
BALL_MIN
```


例如：

```
125 → 135
```


---

### BALL_MAX


保持：

```python
255
```


通常不用修改。

# 13. 零点偏差修正


如果钢球实际中心：

```
0cm
```


但是输出：

```
+0.51cm
```


说明：

存在固定偏差。


增加：

```python
POSITION_ZERO_OFFSET_CM = 0.51
```


计算：

```python
position_cm -= POSITION_ZERO_OFFSET_CM
```


即可修正。
