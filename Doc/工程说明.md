# STM32F407原工程工程说明

## 1. 工程目标

该工程用于非阻塞循迹小车，包含电机与编码器、底盘闭环、灰度循迹、动作库、路线状态机、ICM20948、VL53L1X、HX711、LCD/OLED、K210 和 E220。

## 2. 分层

| 层级 | 作用 |
| --- | --- |
| `Common` | 平台无关状态码和临界区抽象 |
| `BSP` | 芯片外设、引脚、中断、DMA、时基 |
| `Driver` | 器件驱动 |
| `Algorithm` | PID、循迹、姿态、里程 |
| `APP` | 底盘、动作、传感器管理、显示、整车任务 |
| `Route` | 路线规则和赛道实现 |
| `Test` | 专项测试入口 |

```text
APP / Route / Test
        ↓
Algorithm / Driver
        ↓
BSP
        ↓
STM32F407ZG
```

## 3. 启动流程

```text
BSP_InitAll()
→ Driver_Init()
→ App_Init()
→ Scheduler_Init()
→ Scheduler_Run()
```

## 4. 配置入口

| 配置 | 文件 |
| --- | --- |
| 静态任务表 | `APP/app_task_config.h` |
| 专项测试开关 | `Test/test_config.h` |
| 底盘与链路模式 | `BSP/vehicle_config.h` |
| 控制参数 | `Algorithm/control_config.h` |
| 整车状态机 | `APP/task_profile_config.h` |
| 路线选择 | `Route/route_config.h` |
| 灰度来源 | `Driver/drv_gray_sensor.h` |

STM32 工程使用 `DroneProject.uvprojx`；新增固件 `.c` 时同步更新 Keil 工程和 Makefile。USART1 在 DIRECT 与 E220 之间编译期切换。

## 5. 周期建议

- 1 ms：后台和传感器状态机；
- 5 ms：K210 解析；
- 10 ms：按键、编码器、底盘、动作、循迹；
- 20 ms：显示任务；
- 200～500 ms：日志。

## 6. 2026通信系电赛模拟赛B题基础巡线

当前 `Route/route_config.h` 选择 `ROUTE_PROFILE_B_BASIC`。该路线实现位于：

- `Route/route_profile_b_basic.c`
- `Route/route_profile_b_basic.h`

普通路段继续调用 `Algorithm/line_track.c`，因此基础循迹速度、弯道减速、PD参数和丢线保护仍统一在 `Algorithm/control_config.h` 中配置。B题路线文件只处理三项赛道事件：

1. 前半段虚线：中线稳定后丢线时短暂低速直行，快速重新见线即恢复普通巡线；
2. 三角尖头：直行探测窗口结束仍持续丢线时，停止前进并向右原地转向，重新看到中线后恢复普通巡线；
3. 终点停止线：越过三角尖头并再次稳定巡线后，连续检测全黑，立即停车并由 `APP/line_follow_app.c` 非阻塞鸣笛600 ms。

具体状态、参数和测试方法见 `Doc/B题基础巡线说明.md`。
