# STM32F407原工程工程说明

## 1. 工程目标

该工程用于非阻塞循迹小车，包含电机与编码器、底盘闭环、灰度循迹、动作库、路线规则、整车任务状态机、ICM20948、VL53L1X、HX711、LCD/OLED、K210 和 E220。

## 2. 分层

| 层级 | 作用 |
| --- | --- |
| `Common` | 平台无关状态码和临界区抽象 |
| `BSP` | 芯片外设、引脚、中断、DMA、时基 |
| `Driver` | 器件驱动 |
| `Algorithm` | PID、通用循迹、姿态、里程 |
| `Route` | 赛道巡线规则、路段事件和路线控制意图 |
| `APP` | 底盘仲裁、动作、传感器管理、显示和整车任务状态机 |
| `Test` | 专项测试入口，不进入封箱正式任务表 |

```text
APP整车任务状态机
        ↓ 启停与任务目标
Route赛道巡线规则
        ↓ 控制意图
Algorithm / Driver
        ↓
BSP
        ↓
STM32F407ZG
```

`APP/task_profile_*`负责整车从等待、启动、运行到完成或故障的业务流程；`Route/route_profile_*`只负责具体赛道如何巡线、何时转弯以及何时上报到达。两者不能混为同一层。

## 3. 启动流程

```text
BSP_InitAll()
→ Driver_Init()
→ App_Init()
→ TaskProfile_Init()
→ Scheduler_Init()
→ Scheduler_Run()
```

## 4. 两个独立选择入口

| 配置 | 文件 | 当前B题选择 |
| --- | --- | --- |
| 整车任务状态机 | `APP/task_profile_config.h` | `TASK_PROFILE_B_BASIC` |
| 赛道方案 | `Route/route_config.h` | `ROUTE_PROFILE_B_BASIC` |

选择层会检查两者是否匹配。送药整车任务必须配送药赛道，B题基础整车任务必须配B题基础赛道。

其他配置入口：

| 配置 | 文件 |
| --- | --- |
| 静态任务表 | `APP/app_task_config.h` |
| 专项测试开关 | `Test/test_config.h` |
| 底盘与链路模式 | `BSP/vehicle_config.h` |
| 控制参数 | `Algorithm/control_config.h` |
| 灰度来源 | `Driver/drv_gray_sensor.h` |

STM32工程使用`DroneProject.uvprojx`；新增固件`.c`时同步更新Keil工程和Makefile。

## 5. B题基础巡线正式结构

- `APP/task_profile_b_basic.c/.h`：KEY1启动、KEY4停止、运行监控、故障停车、到达鸣笛；
- `Route/route_profile_b_basic.c/.h`：直角、虚线、三角尖头和终点停止线；
- `Algorithm/line_track.c`：普通路段PD循迹；
- `APP/line_follow_app.c`：Route控制意图与底盘控制权之间的通用适配，不承担蜂鸣器和整车完成流程。

正式任务表不包含任何`Test_*`函数。详细参数和测试方法见`Doc/B题基础巡线说明.md`。

## 6. 周期建议

- 1 ms：后台和传感器状态机；
- 5 ms：K210解析，仅视觉任务使用；
- 10 ms：按键、编码器、整车状态机、底盘、动作、巡线；
- 20～100 ms：显示任务；
- 200～500 ms：调试日志，封箱版本可不注册。
