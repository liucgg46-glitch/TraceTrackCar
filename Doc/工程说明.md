# STM32F407 工程说明

## 1. 项目用途

TraceTrackCar 是基于 STM32F407ZG 的非阻塞循迹小车工程，包含电机与编码器、灰度循迹、姿态估计、测距、称重、显示、K210 视觉通信、E220 无线通信、路线管理和整车任务状态机。

## 2. 分层

| 层级 | 职责 |
| --- | --- |
| `Common` | 平台无关状态码和临界区接口 |
| `BSP` | STM32 外设、引脚、DMA、中断和时基 |
| `Driver` | 电机、编码器、IMU、ToF、灰度、显示、E220 等器件驱动 |
| `Algorithm` | PID、循迹、里程和姿态等纯算法 |
| `APP` | 底盘、动作、传感器管理、显示和整车状态机 |
| `Route` | 赛道规则和路线输出 |
| `Test` | 专项测试入口与主机测试 |
| `K210` | K210 端视觉程序和工具 |

依赖方向：

```text
APP / Route / Test
        ↓
Algorithm / Driver
        ↓
BSP
        ↓
STM32F407
```

Algorithm 不直接访问 Driver 或 BSP；Route 只输出控制意图；芯片寄存器和引脚只允许出现在 BSP、启动文件和中断文件中。

## 3. 启动流程

```text
BSP_InitAll()
→ Driver_Init()
→ App_Init()
→ Scheduler_Init()
→ Scheduler_Run()
```

所有周期功能由静态任务表推进。1 ms 任务只做轻量后台维护，不允许加入长延时、死循环或等待外设完成。

## 4. 配置入口

| 文件 | 作用 |
| --- | --- |
| `BSP/vehicle_config.h` | 2WD/4WD 和 USART1 直连/E220 模式 |
| `Algorithm/control_config.h` | 底盘、循迹和动作参数 |
| `Driver/drv_gray_sensor.h` | 灰度传感器来源 |
| `APP/task_profile_config.h` | 整车任务状态机选择 |
| `Route/route_config.h` | 赛道实现选择 |
| `APP/app_task_config.h` | 静态任务表 |
| `Test/test_config.h` | 专项测试编译开关 |

## 5. 构建

- Keil：`DroneProject.uvprojx`
- GNU：根目录 `Makefile`
- 目标芯片：STM32F407ZG

新增或移动参与固件的 `.c` 文件时，同步更新 Keil 工程和 Makefile。

## 6. 跨平台接口

`Common`、`Algorithm`、`Route`、大部分 `APP` 和 `Test` 应与 TI 工程保持同名同义。上层串口只使用：

```c
UART_PORT_K210
UART_PORT_E220
DEBUG_UART_PORT
```

不得在上层直接使用具体 USART、GPIO、DMA 或中断宏。
