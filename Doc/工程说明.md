# STM32F407原工程工程说明

## 1. 工程目标

该工程用于非阻塞循迹小车，包含电机与编码器、底盘闭环、灰度循迹、动作库、路线状态机、ICM20948、VL53L1X、HX711、LCD/OLED、K210 和 E220。

## 2. 分层

| 层级 | 作用 |
| --- | --- |
| `Common` | 平台无关状态码和临界区抽象 |
| `BSP` | 芯片外设、引脚、中断、DMA、时基 |
| `Driver` | 器件驱动 |
| `Algorithm` | PID、循迹、姿态、里程 |
| `APP` | 底盘、动作、传感器管理、显示、整车任务 |
| `Route` | 路线规则和赛道实现 |
| `Test` | 专项测试入口 |

```text
APP / Route / Test
        ↓
Algorithm / Driver
        ↓
BSP
        ↓
STM32F407ZG
```

## 3. 启动流程

```text
BSP_InitAll()
→ Driver_Init()
→ App_Init()
→ Scheduler_Init()
→ Scheduler_Run()
```

## 4. 配置入口

| 配置 | 文件 |
| --- | --- |
| 静态任务表 | `APP/app_task_config.h` |
| 专项测试开关 | `Test/test_config.h` |
| 底盘与链路模式 | `BSP/vehicle_config.h` |
| 控制参数 | `Algorithm/control_config.h` |
| 整车状态机 | `APP/task_profile_config.h` |
| 路线选择 | `Route/route_config.h` |
| 灰度来源 | `Driver/drv_gray_sensor.h` |

STM32 工程使用 `DroneProject.uvprojx`；新增固件 `.c` 时同步更新 Keil 工程和 Makefile。USART1 在 DIRECT 与 E220 之间编译期切换。

## 5. 周期建议

- 1 ms：后台和传感器状态机；
- 5 ms：K210 解析；
- 10 ms：按键、编码器、底盘、动作、循迹；
- 20 ms：显示任务；
- 200～500 ms：日志。
