## 2. ICM20948模块接线

原工程使用STM32F407的硬件SPI2。`MOSI`和`MISO`均以STM32主控为参照：

- MOSI：Master Out Slave In，STM32输出、ICM20948输入；
- MISO：Master In Slave Out，ICM20948输出、STM32输入。

| ICM20948模块丝印 | SPI标准含义 | STM32F407连接 |
| --- | --- | --- |
| `VCC` | 模块电源 | `3.3V`（仍须以模块规格为准） |
| `GND` | 电源地 | `GND` |
| `SCL / SCLK` | SPI串行时钟 | `PB13 / SPI2_SCK` |
| `SDA / SDI / MOSI` | 模块串行数据输入 | `PB15 / SPI2_MOSI` |
| `AD0 / SDO / MISO` | 模块串行数据输出 | `PB14 / SPI2_MISO` |
| `NCS / CS` | 软件片选，低电平有效 | `PE5` |
| `INT` | 中断输出 | 当前原工程未使用，可不接 |
| `EDA / AUX_DA` | 辅助I2C数据线 | 不接 |
| `ECL / AUX_CL` | 辅助I2C时钟线 | 不接 |
| `FSYNC` | 外部帧同步输入 | 未使用时接`GND` |

```text
模块 VCC       → 3.3V
模块 GND       → GND
模块 SCL/SCLK  → PB13
模块 SDA/SDI   → PB15    （STM32端名称：MOSI）
模块 AD0/SDO   → PB14    （STM32端名称：MISO）
模块 NCS/CS    → PE5
模块 INT       → 当前不接
模块 EDA       → 不接
模块 ECL       → 不接
模块 FSYNC     → GND
```

`NCS/CS`不能永久接地。驱动会在每次寄存器访问开始前将PE5拉低，访问完成后再拉高。

## 4. 电机和编码器

| 位置 | PWM | 方向脚 | 编码器 |
| --- | --- | --- | --- |
| FL | PC6 / TIM8_CH1 | PD0、PD1 | PE9、PE11 / TIM1 |
| FR | PC7 / TIM8_CH2 | PD2、PD3 | PA0、PA1 / TIM2 |
| RL | PC8 / TIM8_CH3 | PD4、PD7 | PA6、PA7 / TIM3 |
| RR | PC9 / TIM8_CH4 | PD8、PD9 | PB6、PB7 / TIM4 |

当前 Yahboom 灰度模块启用时工程使用2WD配置，USART3占用`PD8/PD9`，因此不能同时使用4WD右后轮方向脚。

## 5. 其他外设

| 功能 | 引脚 |
| --- | --- |
| 4051 | PC0，PD10～PD12 |
| Yahboom 8路灰度串口 | 模块`5V`→5V、`GND`→GND、模块`RX`→PD8/USART3_TX、模块`TX`→PD9/USART3_RX |
| HX711 | PG3 DOUT、PG4 SCK |
| 红绿灯 | PG5、PG6 |
| 蜂鸣器 | PG7，低电平有效 |
| SWD | PA13、PA14 |

Yahboom模块当前使用串口数字量方式，使用模块串口座而不是I2C座。模块黑线
返回0、白底返回1；Driver向上层保持黑线0、白底4095的`filt`量程，
`line_detect`继续按`filt < threshold`判断压黑线。

通用数字量循迹当前参数为：

```c
#define CONTROL_LINE_BASE_SPEED_CPS       2000
#define CONTROL_LINE_CROSS_SPEED_CPS      1500
#define CONTROL_LINE_MIN_TRACK_SPEED_CPS  1500
#define CONTROL_LINE_TURN_MAX_CPS         1200
#define CONTROL_LINE_KP                   0.30f
#define CONTROL_LINE_KD                   0.04f
```

数字量线路误差使用`1/2`一阶滤波。H题第2项启动时会通过
`LineFollow_SetSpeedProfile()`把基础、弯道和最小速度统一覆盖为2500 cps；
该运行时速度覆盖不修改KP、KD、转向上限和丢线恢复参数。

## 7. 钢球平衡初始参数

当前集中配置位于`Algorithm/ball_balance_config.h`：

- 水平角`BALL_BALANCE_LEVEL_ANGLE_DEG=90.0°`；
- 舵机动态角到钢球加速度符号为`-1`；
- 初始`BALL_BALANCE_B0_MM_S2_PER_DEG=100.0 mm/s²/deg`；
- 控制周期10 ms，连续200 ms无VALID判超时，重新连续3帧VALID后恢复；
- 状态反馈`wn=1.8 rad/s`、`zeta=1.0`，动态角限制±2.5°；
- 最终舵机角度限制80°～180°，每周期最多变化0.3°；
- 参考最大速度80 mm/s、最大加速度160 mm/s²、最大加加速度600 mm/s³；
- 稳定判据为位置误差不超过6 mm、速度不超过10 mm/s并持续250 ms。

水平角、B0、局部平衡角七点表、状态反馈带宽、卡尔曼Q/R和静摩擦参数均需在
机械结构固定后通过实物测试复核，未辨识前不得扩大动态角限制。
