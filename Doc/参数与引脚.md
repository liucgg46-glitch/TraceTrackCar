# STM32F407原工程参数与引脚

## 1. 系统与通信

| 项目 | 当前配置 |
| --- | --- |
| 主控 | STM32F407ZG |
| 软件时基 | SysTick 1 ms |
| 调试串口 | USART1：PA9 TX、PA10 RX，115200 8N1 |
| K210 | USART2：PA2 TX、PA3 RX，115200 8N1 |
| E220 | USART1：PA9 TX、PA10 RX，PE6 AUX |
| I2C | I2C1：PB8 SCL、PB9 SDA，100 kHz |
| ICM20948 | SPI2：PB13 SCLK、PB15 MOSI、PB14 MISO、PE5 CS |
| LCD | 2WD 使用 SPI1；4WD 使用 SPI2；PB12 CS、PC10 DC、PC11 BL |

## 2. 按键

| 按键 | 引脚 |
| --- | --- |
| KEY1 | PE4 |
| KEY2 | PE3 |
| KEY3 | PE2 |
| KEY4 | PE1 |
| KEY5 | PA15 |

## 3. 电机和编码器

| 位置 | PWM | 方向脚 | 编码器 |
| --- | --- | --- | --- |
| FL | PC6 / TIM8_CH1 | PD0、PD1 | PE9、PE11 / TIM1 |
| FR | PC7 / TIM8_CH2 | PD2、PD3 | PA0、PA1 / TIM2 |
| RL | PC8 / TIM8_CH3 | PD4、PD7 | PA6、PA7 / TIM3 |
| RR | PC9 / TIM8_CH4 | PD8、PD9 | PB6、PB7 / TIM4 |

## 4. 其他外设

| 功能 | 引脚 |
| --- | --- |
| 4051 | PC0，PD10～PD12 |
| HX711 | PG3 DOUT、PG4 SCK |
| 红绿灯 | PG5、PG6 |
| 蜂鸣器 | PG7 |
| SWD | PA13、PA14 |

## 5. 参数位置

| 参数 | 文件 |
| --- | --- |

| 灰度来源和通道方向 | `Driver/drv_gray_sensor.h` |

| 状态机 | `APP/task_profile_config.h` |
