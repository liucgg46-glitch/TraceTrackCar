## 2. ICM20948模块接线

原工程使用STM32F407的硬件SPI2。`MOSI`和`MISO`均以STM32主控为参照：

- MOSI：Master Out Slave In，STM32输出、ICM20948输入；
- MISO：Master In Slave Out，ICM20948输出、STM32输入。

| ICM20948模块丝印 | SPI标准含义 | STM32F407连接 |
| --- | --- | --- |
| `VCC` | 模块电源 | `3.3V`（仍须以模块规格为准） |
| `GND` | 电源地 | `GND` |
| `SCL / SCLK` | SPI串行时钟 | `PB13 / SPI2_SCK` |
| `SDA / SDI / MOSI` | 模块串行数据输入 | `PB15 / SPI2_MOSI` |
| `AD0 / SDO / MISO` | 模块串行数据输出 | `PB14 / SPI2_MISO` |
| `NCS / CS` | 软件片选，低电平有效 | `PE5` |
| `INT` | 中断输出 | 当前原工程未使用，可不接 |
| `EDA / AUX_DA` | 辅助I2C数据线 | 不接 |
| `ECL / AUX_CL` | 辅助I2C时钟线 | 不接 |
| `FSYNC` | 外部帧同步输入 | 未使用时接`GND` |

```text
模块 VCC       → 3.3V
模块 GND       → GND
模块 SCL/SCLK  → PB13
模块 SDA/SDI   → PB15    （STM32端名称：MOSI）
模块 AD0/SDO   → PB14    （STM32端名称：MISO）
模块 NCS/CS    → PE5
模块 INT       → 当前不接
模块 EDA       → 不接
模块 ECL       → 不接
模块 FSYNC     → GND
```

`NCS/CS`不能永久接地。驱动会在每次寄存器访问开始前将PE5拉低，访问完成后再拉高。

## 7. 钢球平衡初始参数

当前集中配置位于`Algorithm/ball_balance_config.h`。滚球控制链路已改为
“外环位置P控制 + 内环速度PI控制”，`BallReference`文件仍保留在工程中，
但当前闭环不再使用参考轨迹的位置、速度和加速度。

- 水平角`BALL_BALANCE_LEVEL_ANGLE_DEG=93.0°`；
- 舵机动态角到钢球加速度符号为`BALL_BALANCE_SERVO_TO_ACCEL_SIGN=-1`；
- 默认`BALL_BALANCE_B0_MM_S2_PER_DEG=15.0 mm/s²/deg`，仅用于卡尔曼预测模型；
- 控制周期10 ms，连续600 ms无VALID判超时，重新连续2帧VALID后恢复；
- 外环`BALL_BALANCE_POSITION_KP=1.5`，目标速度限幅为±80 mm/s；
- 目标速度加速度限制为160 mm/s²，位置死区为3 mm；
- 内环`BALL_BALANCE_VELOCITY_KP=0.15`，`BALL_BALANCE_VELOCITY_KI=0.80`；
- 速度低通滤波时间常数50 ms；
- 舵机命令最大速度120°/s、最大加速度2500°/s²、角度跟踪时间常数30 ms；
- 运动控制过程中不再使用0.4°舵机目标死区，小角度变化由速度估计、低通滤波、舵机运动整形和HOLD抑制；
- 最终舵机绝对角仍限制在0°～180°，独立滚球机械安全端点待确认；
- 有效测量接近±105 mm边缘或连续2次被卡尔曼创新拒绝时，估计器直接重捕获到K210实测位置；
- 误差不超过3 mm、滤波速度不超过3 mm/s、目标速度不超过3 mm/s且舵机命令速度接近0，连续250 ms后进入HOLD；
- HOLD记录并固定当前实际舵机命令角`hold_servo_angle`，冻结速度积分，不要求积分回零；
- HOLD在误差超过6 mm、目标变化或控制关闭时退出；短暂无新VALID帧但APP仍判定视觉有效时不退出。

以上是代码默认值，不代表实物辨识结论。水平角、B0、局部平衡角七点表、
位置/速度增益、卡尔曼Q/R和HOLD阈值均需在机械结构固定后通过实物测试复核。

### 7.1 先看哪些串口字段

当前滚球联调任务每100 ms输出一行`BB,...`。调参数前先同时观察：

- `raw_x10`：K210原始实际位置，单位0.1 mm；
- `est_x10`、`vel_x10`：估计位置和估计器原始速度；
- `poserr_x10`：目标位置减估计位置后的误差；
- `targetv_x10`：外环位置P生成并经加速度限制后的目标速度；
- `fvel_x10`：送入速度PI的低通速度；
- `velerr_x10`：目标速度减低通速度后的速度误差；
- `p_x100`：速度P项角度；
- `int_x100`：速度积分角；
- `dyn_x100`：速度PI合成并按舵机方向换符号后的动态角；
- `eq_x100`：当前位置对应的局部平衡角；
- `req_x100`：舵机绝对限幅前的请求角；
- `servo_x100`：经过绝对限幅和运动整形后的最终舵机命令角；
- `servov_x10`：舵机命令变化速度，单位0.1°/s；
- `hold_active`、`hold_servo_x100`：到点保持状态和冻结的舵机角；
- `abs_limited`、`integral_blocked`：绝对角限幅和抗积分饱和状态；
- `timeout`、`reject`、`locked`：视觉超时、卡尔曼创新拒绝和目标点保持标志。

如果`targetv_x10`已经到限幅，说明外环在要求快速回正；如果`dyn_x100`变化很小
但`velerr_x10`长期不为0，优先检查`VELOCITY_KP/KI`；如果`req_x100`已经到位但
`servo_x100`仍在追赶，说明慢的是舵机速度/加速度整形。若输出角度正确但实物
运动方向不对，应先检查舵机方向、连杆和`BALL_BALANCE_SERVO_TO_ACCEL_SIGN`。

### 7.2 参数调大、调小的影响

| 参数 | 什么时候调 | 调大后的影响 | 调小后的影响 |
|---|---|---|---|
| `BALL_BALANCE_POSITION_KP` | 大误差下目标速度建立太慢或太猛 | 同样位置误差给出更大目标速度，整体更快，也更容易超调 | 外环更柔和，长距离响应变慢 |
| `BALL_BALANCE_TARGET_VELOCITY_MAX_MM_S` | 远距离移动太慢或冲得太快 | 允许更高目标速度，长距离更快 | 限制整体速度，端点和过目标风险更低 |
| `BALL_BALANCE_TARGET_ACCEL_MAX_MM_S2` | 目标变化时速度命令太突兀或太迟缓 | 目标速度更快变化，响应更利落 | 速度命令更平滑，目标切换更慢 |
| `BALL_BALANCE_POSITION_DEADBAND_MM` | 到点附近仍生成小速度命令 | 更容易把近目标误差视为0，利于HOLD | 近目标也会继续修正，精度更严但更易抖 |
| `BALL_BALANCE_VELOCITY_KP` | 实际速度跟不上目标速度 | 速度误差立即给出更大角度，响应更快 | 速度环更软，振荡和噪声耦合更少 |
| `BALL_BALANCE_VELOCITY_KI` | 静摩擦导致长期速度误差 | 积分更快建立倾角，克服静摩擦更强 | 积分更慢，超调风险更低 |
| `BALL_BALANCE_VELOCITY_FILTER_TIME_S` | 球不动时`vel_x10`跳动并带动舵机 | 速度更平滑，但真实速度反馈延迟增加 | 速度响应更快，但视觉噪声更容易传到PI |
| `BALL_BALANCE_SERVO_MAX_SPEED_DEG_S` | `servo_x100`长时间追不上请求角 | 大角度移动更快，过大时机械动作更突然 | 更柔和，但远距离回正延迟增加 |
| `BALL_BALANCE_SERVO_MAX_ACCEL_DEG_S2` | 舵机起步或反向仍显得慢 | 更快建立速度和反向，过大时顿挫增加 | 起步、停止更顺滑，但响应更慢 |
| `BALL_BALANCE_SERVO_TRACK_TIME_S` | 目标附近舵机仍小幅抖动 | 接近请求角时更柔和、更抗角度噪声 | 更紧跟瞬时请求角，反应更快但更容易抖 |
| `BALL_BALANCE_TARGET_LOCK_ENTER_ERROR_MM` | 已经很接近目标但迟迟不HOLD | 更容易进入HOLD，但最终允许误差变大 | 到点精度更严，但可能被摩擦卡在阈值外 |
| `BALL_BALANCE_TARGET_LOCK_EXIT_ERROR_MM` | HOLD后因位置噪声频繁重新动作 | HOLD滞环更宽、更稳，但真实偏移后恢复较慢 | 更快响应再次偏移，也更容易被噪声解锁 |
| `BALL_BALANCE_TARGET_LOCK_SPEED_MM_S` | 经过目标点时被误判成停稳 | 要求速度更低才HOLD，抗误判更强 | 更快HOLD，但可能在未完全停稳时锁住 |
| `BALL_BALANCE_TARGET_LOCK_TIME_MS` | 经过目标点时被误判成到达 | 需要稳定更久才HOLD | 更快锁舵，但抗噪声能力下降 |
| `BALL_ESTIMATOR_EDGE_RESET_POSITION_MM` | `raw_x10`已到边缘但`est_x10`迟迟没跟上 | 更早按实测边缘重捕获估计器 | 更少重置估计器，但边缘救球可能变慢 |
| `BALL_ESTIMATOR_REJECT_RESET_COUNT` | 连续`reject=1`后舵机仍不按实测位置动作 | 更少拒绝次数就重捕获，响应更快 | 更保守，减少单次误检造成的重置 |

### 7.3 推荐调节顺序

1. 先确认`raw_x10`右正左负、单位正确，舵机方向正确；这些错误不能靠调增益解决。
2. 先将`BALL_BALANCE_VELOCITY_KI`设为0，只调`BALL_BALANCE_VELOCITY_KP`，
   使实际速度能够跟随目标速度且不过度振荡。
3. 再逐渐增加`BALL_BALANCE_VELOCITY_KI`，直到能够自然克服静摩擦；每次建议只改
   10%～20%，同时观察`integral_blocked`是否频繁触发。
4. 再调整`BALL_BALANCE_POSITION_KP`和`BALL_BALANCE_TARGET_VELOCITY_MAX_MM_S`，
   决定整体运行速度和长距离回正力度。
5. 最后调整HOLD阈值和保持时间；到点后仍动作时观察`hold_active`是否为1，
   以及`servov_x10`是否已经接近0。
6. 若出现快速冲向端点，应立即断开舵机电源并检查机械行程、方向符号和绝对角限幅。

### 7.4 串级控制和HOLD说明

每个控制周期先由外环计算：

```c
position_error = target_position_mm - estimated_position_mm;
target_velocity_raw = BALL_BALANCE_POSITION_KP * position_error;
```

当位置误差进入`BALL_BALANCE_POSITION_DEADBAND_MM`后目标速度置0；随后目标速度
经过最大速度和加速度限制，避免按键目标突变时速度指令阶跃。内环速度PI计算：

```c
velocity_error = target_velocity - filtered_velocity_mm_s;
velocity_control_angle =
    BALL_BALANCE_VELOCITY_KP * velocity_error + velocity_integral;
requested_servo_angle =
    equilibrium_angle_deg
    + BALL_BALANCE_SERVO_TO_ACCEL_SIGN * velocity_control_angle;
```

积分只在正常有效闭环中累积。请求角已经在180°且速度误差还要求继续增大舵机角时，
或请求角已经在0°且速度误差还要求继续减小舵机角时，积分被冻结；速度误差要求舵机
离开限位时允许积分恢复。普通目标变化不清零积分；HOLD和短暂无新VALID帧只冻结积分；
控制关闭或视觉超时后重新获得跟踪会清零目标速度、速度积分，并重新初始化速度滤波。

误差不超过3 mm、滤波速度不超过3 mm/s、目标速度不超过3 mm/s且舵机命令速度接近0，
持续250 ms后进入HOLD。进入HOLD时记录当前实际舵机命令角并固定输出，允许保持角
不是水平角；退出后从当前保持角继续经过原舵机速度、加速度限制平滑恢复闭环。
