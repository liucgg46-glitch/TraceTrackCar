# STM32F407 参数与引脚

## 1. 系统参数

| 项目 | 当前配置 |
| --- | --- |
| 主控 | STM32F407ZG |
| 软件时基 | SysTick 1 ms |
| UART | 115200，8N1 |
| I2C1 | 100 kHz，PB8/PB9 |
| 电机 PWM | TIM8 |
| 调试接口 | SWD：PA13/PA14 |

控制增益、轮径、编码器每圈计数和灰度阈值以源码配置头文件为准。

## 2. 编译期选择

```c
/* BSP/vehicle_config.h */
VEHICLE_DRIVE_MODE_2WD
VEHICLE_DRIVE_MODE_4WD
VEHICLE_UART1_LINK_DIRECT
VEHICLE_UART1_LINK_E220
```

2WD 下 PA5/PA6/PA7 可用于 SPI1；4WD 下 PA6/PA7 被左后编码器占用，LCD 改用 SPI2。

## 3. 通信和总线

| 设备 | 接口 | 引脚 |
| --- | --- | --- |
| 调试串口 / E220 | USART1 | PA9 TX，PA10 RX，PE6 AUX |
| K210 | USART2 | PA2 TX，PA3 RX |
| I2C 设备 | I2C1 | PB8 SCL，PB9 SDA |
| ICM20948 | SPI2 | PB13 SCLK，PB15 MOSI，PB14 MISO，PE5 CS |
| LCD 控制 | GPIO | PB12 CS，PC10 DC，PC11 BL |
| LCD SPI（2WD） | SPI1 | PA5 SCLK，PA7 MOSI，PA6 MISO |
| LCD SPI（4WD） | SPI2 | PB13 SCLK，PB15 MOSI，PB14 MISO |

LCD RESET 当前没有统一固定引脚，接线前按实物模块和 BSP 配置确认。

## 4. 电机和编码器

### 电机

| 位置 | PWM | 方向 1 | 方向 2 |
| --- | --- | --- | --- |
| 左前 FL | PC6 / TIM8_CH1 | PD0 | PD1 |
| 右前 FR | PC7 / TIM8_CH2 | PD2 | PD3 |
| 左后 RL | PC8 / TIM8_CH3 | PD4 | PD7 |
| 右后 RR | PC9 / TIM8_CH4 | PD8 | PD9 |

### 编码器

| 位置 | A 相 | B 相 | 定时器 |
| --- | --- | --- | --- |
| 左前 FL | PE9 | PE11 | TIM1 |
| 右前 FR | PA0 | PA1 | TIM2 |
| 左后 RL | PA6 | PA7 | TIM3 |
| 右后 RR | PB6 | PB7 | TIM4 |

后轮资源只在 4WD 模式启用。电机方向和编码器正负方向必须实车低速确认。

## 5. 其他外设

| 功能 | 引脚 |
| --- | --- |
| 4051 模拟输出 | PC0 / ADC1_IN10 |
| 4051 选择线 | PD10、PD11、PD12 |
| HX711 DOUT / SCK | PG3 / PG4 |
| 红灯 / 绿灯 | PG5 / PG6 |
| 蜂鸣器 | PG7 |
| KEY1～KEY4 | PE4、PE3、PE2、PE1 |
| KEY5 | PA15 |
| 普通 GPIO 测试灯 | PC13 |

PA15 占用 JTDI，但不影响 PA13/PA14 两线 SWD。

## 6. 参数位置

| 参数类型 | 文件 |
| --- | --- |
| 底盘、循迹和动作 | `Algorithm/control_config.h` |
| 编码器映射、反向和滤波 | `Driver/drv_encoder.h` |
| 灰度来源 | `Driver/drv_gray_sensor.h` |
| 灰度阈值 | `Algorithm/line_detect.h` |
| 姿态与航向 | `Driver/drv_icm20948.h`、`Algorithm/attitude_estimator.h` |
| 路线选择 | `Route/route_config.h` |
| 整车状态机选择 | `APP/task_profile_config.h` |
