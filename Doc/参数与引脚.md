## 2. ICM20948模块接线

原工程使用STM32F407的硬件SPI2。`MOSI`和`MISO`均以STM32主控为参照：

- MOSI：Master Out Slave In，STM32输出、ICM20948输入；
- MISO：Master In Slave Out，ICM20948输出、STM32输入。

| ICM20948模块丝印 | SPI标准含义 | STM32F407连接 |
| --- | --- | --- |
| `VCC` | 模块电源 | `3.3V`（仍须以模块规格为准） |
| `GND` | 电源地 | `GND` |
| `SCL / SCLK` | SPI串行时钟 | `PB13 / SPI2_SCK` |
| `SDA / SDI / MOSI` | 模块串行数据输入 | `PB15 / SPI2_MOSI` |
| `AD0 / SDO / MISO` | 模块串行数据输出 | `PB14 / SPI2_MISO` |
| `NCS / CS` | 软件片选，低电平有效 | `PE5` |
| `INT` | 中断输出 | 当前原工程未使用，可不接 |
| `EDA / AUX_DA` | 辅助I2C数据线 | 不接 |
| `ECL / AUX_CL` | 辅助I2C时钟线 | 不接 |
| `FSYNC` | 外部帧同步输入 | 未使用时接`GND` |

```text
模块 VCC       → 3.3V
模块 GND       → GND
模块 SCL/SCLK  → PB13
模块 SDA/SDI   → PB15    （STM32端名称：MOSI）
模块 AD0/SDO   → PB14    （STM32端名称：MISO）
模块 NCS/CS    → PE5
模块 INT       → 当前不接
模块 EDA       → 不接
模块 ECL       → 不接
模块 FSYNC     → GND
```

`NCS/CS`不能永久接地。驱动会在每次寄存器访问开始前将PE5拉低，访问完成后再拉高。

## 7. 钢球平衡初始参数

当前集中配置位于`Algorithm/ball_balance_config.h`：

- 水平角`BALL_BALANCE_LEVEL_ANGLE_DEG=93.0°`；
- 舵机动态角到钢球加速度符号为`-1`；
- 默认`BALL_BALANCE_B0_MM_S2_PER_DEG=15.0 mm/s²/deg`；
- 控制周期10 ms，连续600 ms无VALID判超时，重新连续2帧VALID后恢复；
- 状态反馈`wn=1.8 rad/s`、`zeta=1.15`，普通反馈动态角限制为±30°；
- 最终命令受`BALL_BALANCE_SERVO_SAFE_MIN_DEG/MAX_DEG`机械安全角限制；当前暂时引用Driver的0°～180°标定范围，独立滚球安全端点待确认；
- 估计速度滤波时间常数50 ms，速度死区按3 mm/s进入、6 mm/s退出，扰动滤波时间常数200 ms；
- 参考加速度前馈和扰动补偿默认关闭，动态角滤波时间常数60 ms；
- 舵机命令最大速度120°/s、最大加速度2500°/s²、角度跟踪时间常数30 ms；0.4°死区只作用于正常反馈角，脱困角不经过死区；
- 最终目标误差大于5 mm、低通速度小于3 mm/s且视觉新鲜持续300 ms后，脱困状态从`IDLE`进入`RAMP`；
- `RAMP`以10°/s连续增长，不设置固定脱困角上限，只按当前正常角剩余的机械安全空间限幅；
- 从RAMP起点累计向目标移动1.5 mm且连续2帧同向运动后进入`DECAY`；DECAY按运动进度、向目标速度和剩余误差单调撤销；
- DECAY远离目标再次静止300 ms时保留剩余脱困角并直接回到RAMP；清零后进入250 ms冷却；
- 参考最大速度80 mm/s、最大加速度160 mm/s²、最大加加速度600 mm/s³；
- 误差不超过3 mm、速度不超过6 mm/s并持续250 ms后置位到点标志；
- 到点条件满足后记录并固定`hold_servo_angle`；误差超过6 mm、目标变化、视觉失效或控制关闭时退出，并从保持角平滑恢复。
- 视觉短暂降级时舵机保持当前角度，避免无VALID瞬间拉回水平角造成摆杆大幅甩动。
- 有效测量接近±105 mm边缘或连续2次被卡尔曼创新拒绝时，估计器直接重捕获到K210实测位置。

以上是代码默认值，不代表实物辨识结论。水平角、B0、局部平衡角七点表、
状态反馈带宽、卡尔曼Q/R和静摩擦参数均需在机械结构固定后通过实物测试复核。

### 7.1 先看哪些串口字段

当前滚球联调任务每100 ms输出一行`BB,...`。调参数前先同时观察：

- `raw_x10`：K210原始实际位置，单位0.1 mm；
- `est_x10`、`vel_x10`：估计位置和估计器原始速度；
- `fvel_x10`、`fdist_x10`：真正送入反馈计算的滤波速度和滤波扰动；
- `ref_x10`：当前平滑参考位置，不是最终按键目标；
- `refa_x10`、`refaff_x10`：原始参考加速度和降权后的实际前馈加速度；
- `dyn_x100`：状态反馈请求的动态角；
- `breakaway_state`、`breakaway_x100`：脱困状态和当前脱困角；
- `breakaway_start_x100`、`breakaway_progress_x10`：钢球启动时的脱困角和启动后的向目标进度；
- `hold_active`、`hold_servo_x100`：到点保持状态和冻结的舵机角；
- `poserr_x10`、`fvel_x10`：位置误差和参与反馈的滤波速度；
- `servo_x100`：经过物理行程限制和运动整形后的舵机命令角；
- `servov_x10`：舵机命令变化速度，单位0.1°/s；
- `timeout`、`reject`、`locked`：视觉超时、卡尔曼创新拒绝和目标点锁舵标志。

如果`ref_x10`还没有走到按键目标，说明慢的是参考轨迹；如果`dyn_x100`已经很大
但`servo_x100`仍在追赶，说明慢的是舵机运动整形；如果两者已经到位但实物舵机
角度不对，应检查舵机供电、连杆和PWM标定，而不是继续增加控制增益。

### 7.2 参数调大、调小的影响

| 参数 | 什么时候调 | 调大后的影响 | 调小后的影响 |
|---|---|---|---|
| `BALL_BALANCE_B0_MM_S2_PER_DEG` | `dyn_x100`长期太小或太大 | 同样加速度换算出的角度更小，动作更弱 | 同样加速度换算出的角度更大，动作更强，过小会振荡或撞端 |
| `BALL_BALANCE_NATURAL_FREQ_RAD_S` | 大误差回正普遍太慢 | 位置和速度反馈同时增强，回正更快，也更容易过冲 | 反馈变软、过冲减少，但回正更慢 |
| `BALL_BALANCE_DAMPING_RATIO` | 小球到目标附近仍冲过头 | 速度制动增强，过冲减少，但过大会显得拖沓 | 制动减弱、动作更积极，但更容易来回摆动 |
| `BALL_BALANCE_VELOCITY_FILTER_TIME_S` | 球不动时`vel_x10`跳动并带动舵机 | 滤波更强、舵机更稳，但真实速度反馈延迟增加 | 速度响应更快，但视觉噪声更容易传到舵机 |
| `BALL_BALANCE_VELOCITY_DEADBAND_MM_S` | 静止时仍有小幅假速度 | 更容易把低速视为0，减少抽动，但会损失低速反馈 | 保留更多低速信息，但更容易受噪声影响 |
| `BALL_BALANCE_VELOCITY_DEADBAND_EXIT_MM_S` | 速度在零附近反复进入、退出死区 | 需要更明显的运动才恢复速度反馈，抗抖更强 | 更快恢复低速反馈，但死区状态更容易切换 |
| `BALL_BALANCE_REFERENCE_ACCEL_FEEDFORWARD_GAIN` | 单向运动途中舵机随参考加速/刹车反复换向 | 更紧跟参考加速度，动作更积极，也更容易上下摆 | 削弱参考切换冲击，主要依靠位置和速度反馈 |
| `BALL_BALANCE_DYNAMIC_FILTER_TIME_S` | `dyn_x100`正负方向切换过快 | 动态角更平滑，但建立最大角度更慢 | 动态角跟随更快，但舵机更容易频繁换向 |
| `BALL_BALANCE_DYNAMIC_HARD_LIMIT_DEG` | 大误差时水管摆幅过大、球被甩到边缘 | 允许普通反馈给更大角度，远距离回正更猛 | 压低普通反馈角，减少甩动；过小会依赖脱困补偿慢慢加角 |
| `BALL_BALANCE_SERVO_MAX_SPEED_DEG_S` | `servo_x100`长时间追不上请求角 | 大角度移动更快，过大时机械动作更突然 | 更柔和，但远距离回正延迟增加 |
| `BALL_BALANCE_SERVO_MAX_ACCEL_DEG_S2` | 舵机起步或反向仍显得慢 | 更快建立速度和反向，过大时顿挫增加 | 起步、停止更顺滑，但响应更慢 |
| `BALL_BALANCE_SERVO_TRACK_TIME_S` | 目标附近舵机仍小幅抖动 | 接近请求角时更柔和、更抗角度噪声 | 更紧跟瞬时请求角，反应更快但更容易抖 |
| `BALL_BALANCE_SERVO_COMMAND_DEADBAND_DEG` | 0.1°级请求变化仍反复更新PWM | 忽略更多微小变化，舵机更稳但小修正变慢 | 保留更多小角度修正，但更容易微抖 |
| `BALL_REFERENCE_MAX_SPEED_MM_S` | `ref_x10`长距离移动太慢 | 中段参考移动更快 | 长距离目标切换更慢 |
| `BALL_REFERENCE_MAX_ACCEL_MM_S2` | `ref_x10`起步和刹车太慢 | 更快起步和制动 | 轨迹更柔和但整体耗时增加 |
| `BALL_REFERENCE_MAX_JERK_MM_S3` | `refv_x10`建立速度太慢 | 加速度建立更快，目标切换更利落 | 加速度变化更柔和，响应更慢 |
| `BALL_BALANCE_BREAKAWAY_IDLE_DWELL_MS` | 小球不动后补偿出现太迟 | 等待更久再进入RAMP，误判更少 | 更快脱困，过小会把正常低速误判为卡滞 |
| `BALL_BALANCE_BREAKAWAY_RESTART_DWELL_MS` | DECAY中再次停住后恢复太慢 | 更不容易重复增角，但再次卡住时等待更久 | 更快从剩余角继续RAMP，也更容易误判 |
| `BALL_BALANCE_BREAKAWAY_GROWTH_DEG_S` | `breakaway_x100`增长太慢 | 更快增加角度，也更容易在刚动时冲得过快 | 加角更平滑，但脱困等待时间增加 |
| `BALL_BALANCE_BREAKAWAY_STUCK_SPEED_MM_S` | 正常低速移动仍被判定为卡住 | 允许更高速度时继续增角，脱困更积极但误判增多 | 只有更接近静止时才增角，误判更少 |
| `BALL_BALANCE_BREAKAWAY_START_PROGRESS_MM` | 视觉抖动误判钢球已启动 | 需要更大累计位移才进入DECAY，抗噪更强 | 更早进入DECAY，但可能把视觉跳动当成启动 |
| `BALL_BALANCE_BREAKAWAY_FORWARD_STEP_MIN_MM` | 累计位移足够但运动方向不连续 | 每帧需要更明显的同向运动，抗噪更强 | 更容易满足连续同向帧，但噪声误判概率增加 |
| `BALL_BALANCE_BREAKAWAY_FORWARD_FRAME_COUNT` | 单帧跳变就进入DECAY | 需要更多连续向目标帧，确认更稳 | 更快确认启动，但更依赖单帧位置质量 |
| `BALL_BALANCE_BREAKAWAY_DECAY_RATE_DEG_S` | 球运动后脱困角残留过久 | DECAY更快跟随目标角下降 | 保留推力更久，但靠近目标时可能过冲 |
| `BALL_BALANCE_BREAKAWAY_CLEAR_RATE_DEG_S` | 目标变化或越过目标后撤角太慢 | 异常清零更快，但角变化更急 | 清零更柔和，但错误方向推力保留更久 |
| `BALL_BALANCE_BREAKAWAY_DECAY_SPEED_SCALE_MM_S` | 速度较快时仍保留过多脱困角 | 同样速度造成的额外撤角减弱 | 对速度更敏感，运动快时撤销更快 |
| `BALL_BALANCE_BREAKAWAY_DECAY_PROGRESS_WEIGHT` | DECAY进度与剩余误差的影响比例不合适 | 更依赖启动后的累计进度撤角 | 更依赖当前剩余误差撤角 |
| `BALL_BALANCE_BREAKAWAY_COOLDOWN_MS` | 补偿刚释放就再次触发 | 延长重新触发间隔，反复抽动更少 | 卡住后可更快再次脱困，也更容易反复触发 |
| `BALL_BALANCE_SERVO_SAFE_MIN_DEG/MAX_DEG` | 齿条接近机械端点 | 扩大范围会增加可用角，也会提高撞端风险 | 收窄范围更安全，但可用控制角减少 |
| `BALL_BALANCE_TARGET_LOCK_ENTER_ERROR_MM` | 已经很接近目标但迟迟不锁舵 | 更容易进入锁定，但最终允许误差变大 | 到点精度更严，但可能被摩擦卡在阈值外 |
| `BALL_BALANCE_TARGET_LOCK_EXIT_ERROR_MM` | 到点后因位置噪声频繁重新动作 | 锁定滞环更宽、更稳，但真实偏移后恢复较慢 | 更快响应再次偏移，也更容易被噪声解锁 |
| `BALL_BALANCE_TARGET_LOCK_TIME_MS` | 经过目标点时被误判成到达 | 需要稳定更久才锁定 | 更快锁舵，但可能在小球尚未真正停稳时锁住 |
| `BALL_ESTIMATOR_EDGE_RESET_POSITION_MM` | `raw_x10`已到边缘但`est_x10`迟迟没跟上 | 更早按实测边缘重捕获估计器 | 更少重置估计器，但边缘救球可能变慢 |
| `BALL_ESTIMATOR_REJECT_RESET_COUNT` | 连续`reject=1`后舵机仍不按实测位置动作 | 更少拒绝次数就重捕获，响应更快 | 更保守，减少单次误检造成的重置 |

### 7.3 推荐调节顺序

1. 先确认`raw_x10`右正左负、单位正确，舵机方向正确；这些错误不能靠调增益解决。
2. 标定`BALL_BALANCE_LEVEL_ANGLE_DEG`和局部平衡角表，使球在不同位置附近不会
   因机械重心偏差持续自行滚动。
3. 暂时观察`breakaway_x100=0`时的普通响应。回正普遍太慢时，先小幅降低`B0`
   或提高`wn`；大误差时水管摆幅太大时，先降低`BALL_BALANCE_DYNAMIC_HARD_LIMIT_DEG`。
   一次只改一个，建议每次变化10%～20%。
4. 小球目标外静止时观察`breakaway_x100`是否沿正确方向持续增长；增长很久仍不动时，
   先确认机构没有机械卡死，再小幅提高`BALL_BALANCE_BREAKAWAY_GROWTH_DEG_S`。
   脱困角不设固定上限，必须先完成`BALL_BALANCE_SERVO_SAFE_MIN_DEG/MAX_DEG`实物标定。
5. 小球一动就过冲时，优先提高脱困释放速度或降低增长速度；如果球没动但舵机上下抽动，
   重点看`breakaway_progress_x10`和连续同向帧，必要时提高`BALL_BALANCE_BREAKAWAY_START_PROGRESS_MM`
   或`BALL_BALANCE_BREAKAWAY_FORWARD_FRAME_COUNT`。到点后仍动作时观察`hold_active`是否为1，
   并按需要调整进入、退出阈值和锁定时间。
6. 最后调舵机运动整形：先用最大加速度解决起步和反向延迟，再用跟踪时间常数
   消除目标附近的卡顿；不要同时大幅提高最大速度和最大加速度。
7. 出现来回摆动时，按“先提高`zeta`，再降低`wn`，最后降低脱困增长速度”的顺序
   处理；出现快速冲向端点时立即断开舵机电源并检查机械行程。

### 7.4 近目标偏差和摩擦补偿依据

目标外长期不动通常是静摩擦或局部管道形变造成的死区。当前采用渐增脱困角：
脱困使用`IDLE → RAMP → DECAY → COOLDOWN`状态机。最终目标误差大于5 mm、
低通速度小于3 mm/s且视觉新鲜持续300 ms后进入RAMP，从当前剩余角连续增大；
累计向目标移动1.5 mm且连续2帧同向后进入DECAY。DECAY从实际启动角开始，综合
启动后进度、向目标速度和剩余误差单调减小；若远离目标再次静止300 ms，则保留
剩余角直接回到RAMP。到点、越过目标、目标变化、视觉失效或控制关闭时快速平滑
清零并进入250 ms冷却。正常反馈角单独经过0.4°死区，脱困角在死区之后相加。

误差不超过3 mm且速度不超过6 mm/s持续250 ms后进入真实HOLD，记录并固定当前
稳定舵机角。误差超过6 mm、目标变化、视觉失效或控制关闭时退出HOLD，现有舵机
速度和加速度轨迹从保持角平滑恢复控制。

相关方法依据：

- 工业阀门控制中的“knocker”方法使用短脉冲克服静摩擦，说明按需增加脱困作用是
  已有工程方法，而不是仅靠固定PID增益：
  [The Knocker - A Compensator for Stiction in Control Valves](https://www.lunduniversity.lu.se/publication/dd14194f-d600-4fe5-b71e-b46fb5cd73a9)。
- 变幅脉冲研究使用模型无关的幅值调整处理未知静摩擦，与本工程“未动则逐步增角、
  动起来后释放”的思路一致：
  [Actuator stiction compensation via variable amplitude pulses](https://doi.org/10.1016/j.isatra.2018.01.016)。
- 高频dither也能减轻静摩擦，但会主动引入快速小振动；本工程不采用持续抖舵：
  [Asymptotic analysis of the dither effect in systems with friction](https://doi.org/10.1016/S0005-1098(01)00166-2)。
