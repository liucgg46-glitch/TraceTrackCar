# 宏修改方法

> 本文由同名 Word 文档迁移并按当前项目源码校正。Word 原文件保留；后续修改代码时应同步检查本文和 `说明文档.md`。

## 切换双路、四路驱动的宏：BSP/vehicle_config.h

```c
#define VEHICLE_DRIVE_MODE_2WD             2U
#define VEHICLE_DRIVE_MODE_4WD             4U
#ifndef VEHICLE_DRIVE_MODE
#define VEHICLE_DRIVE_MODE                 VEHICLE_DRIVE_MODE_2WD
```

说明：2WD 时 SPI1 可用于 LCD；4WD 时 PA6/PA7 被后编码器占用，当前代码会让 LCD 改用 SPI2，与 ICM-20948 共用总线。

建议：4WD 下在联合验证完成前，将 APP/lcd_ui.h 中的 LCD_UI_ENABLE 设为 0U，暂不使用 LCD。

## 切换灰度来源：Driver/drv_gray_sensor.h

```c
#define GRAY_SENSOR_SOURCE_4051       0U
#define GRAY_SENSOR_SOURCE_MCU_I2C    1U
#define GRAY_SENSOR_SOURCE            GRAY_SENSOR_SOURCE_MCU_I2C
```

## 修改灰度的 8 个默认值：Algorithm/line_detect.h

```c
#define LINE_DETECT_DEFAULT_THRESHOLD_0 1774U
#define LINE_DETECT_DEFAULT_THRESHOLD_1 1830U

#define LINE_DETECT_DEFAULT_THRESHOLD_3 2762U
#define LINE_DETECT_DEFAULT_THRESHOLD_4 2104U
#define LINE_DETECT_DEFAULT_THRESHOLD_5 2505U
#define LINE_DETECT_DEFAULT_THRESHOLD_6 2553U

```

## 启用 LCD：APP/lcd_ui.h

```c
#define LCD_UI_ENABLE                1U
```

注意：要开启在循环中更新lcd还要注册LCD_Update

## 启用 OLED：Driver/drv_oled_i2c.h、APP/oled_ui.h

```c
#define DRV_OLED_I2C_ENABLE          1U
#define OLED_UI_ENABLE               1U
```

注意：要在任务循环中更新 OLED，还需在 APP/app_task_config.h 中注册 OLED_Update
