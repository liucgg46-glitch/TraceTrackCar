# K210 gimbal laser-tracing project status

Date paused: 2026-07-19

## Completed or independently verified

- K210 UART1 TX on IO6 to STM32 USART2 RX is working at 115200 8N1.
- The seven-byte target/laser protocol has been received without checksum, format or overflow errors.
- Night-time black-tape rectangle locking has worked with fixed gain 16 dB and exposure 120000 us.
- Rectangle corner ordering, path-edge subdivision and target advancement have run.
- The STM32 servo closed-loop direction and basic movement have been verified separately.
- A clockwise rectangular lap was achieved in an earlier recognition state, but tape-centre accuracy was not finally accepted.
- Red-laser detection on white paper is accurate and stable.

## Not completed

- Reliable red-laser localization while the laser is inside black electrical tape is not solved.
- The current `laser_detect.py` is an experimental full-tape local-contrast version. It has not passed hardware acceptance and may still miss or falsely lock a reflection.
- A4 translation and rotation have not passed complete closed-loop acceptance.
- The actual latest STM32 Keil project still needs to be exported from the user computer and archived; the older GitHub project is not authoritative.

## Current runtime meaning

- `rect_detect.py`: last black-rectangle candidate; do not retune first.
- `laser_detect.py`: experimental, unverified black-tape contrast search.
- `yuntai_main.py`: segmented rectangular path, dynamic target callback and loss/reacquisition wiring.
- `uart_protocol.py`: verified K210 transmit framing.

## Resume order

1. Keep the servo disabled and validate laser measurement only.
2. Use fixed camera settings and laser-off/laser-on frame differencing to obtain the real black-tape signal; do not rely on a pre-existing detector to measure itself.
3. Build a compact local-contrast candidate from those measurements and reject uniform reflections.
4. Validate four corners and four edge midpoints with the laser stationary, recording valid rate and coordinate error.
5. Test one fixed target with STM32 PID.
6. Restore segmented target advancement and run one clockwise lap.
7. Only then test translated and rotated A4 targets.

## Do not do next

- Do not change the verified black-rectangle threshold or exposure as the first response to a laser failure.
- Do not globally lower the red threshold; it previously caused background false positives.
- Do not treat a retained white cross or old output coordinate as a current detection.
- Do not tune PID while `laser_valid` is unreliable.
- Do not overwrite the real STM32 program with the older GitHub repository.
- Do not copy the whole `backups/` directory back to the SD root.
- Do not mark the current black-tape contrast detector as stable without the eight-position stationary test.
